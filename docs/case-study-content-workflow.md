## Recommended handoff

Use one Word or Google Doc per project for copy, with the project name/URL at the top. A Figma link is useful for selecting imagery or specifying visual/layout changes; a document is easier to review and edit for the written content. Images can be attached as files or exported from identified Figma frames. No new CMS account is required for this handoff.

For each project, supply:

1. Exact project title.
2. Two short description paragraphs: context/need, then approach/work/outcome. Include only outcomes that can be supported.
3. Services actually provided, as a short list.
4. Credits: each person/studio and role, with links if wanted. Say if Credits should be omitted.
5. Images numbered in display order, including the desired first image and homepage thumbnail if different.
6. Optional captions matched to those filenames/numbers. Leave a caption blank when none is wanted.

Replace pending copy and image(s) project by project; update title/description metadata and alt text, then remove the in-progress label/noindex once the content is ready.
