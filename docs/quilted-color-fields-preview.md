# Quilted Yarn color fields draft

Preview: `previews/quilted-color-fields.html#color-study`.

The owner requested a quilt-inspired draft using two supplied patchwork references, while retaining the approved soft Yarn color fields. This is a separate full-page preview; the homepage and the existing comparison page are unchanged.

The draft retains the original eleven moving ribbons and adds a lightweight four-by-four repeating patch treatment. Alternating paper tints vary from 26–46% opacity with a gentle ink shade on their neighbors, creating related fabric tones from the same GBY colors. Fine dashed stitches suggest seams. The patch grid stays stationary while the underlying fields drift; the approved grain and calm reading veil remain above the patches and seams. This avoids extra blurred field layers and full-screen masks.

The draft reuses the exact approved Section 2 copy, typography, layout, +60% timing, native curtains and independent Pause controller. The eleven ribbons pause when requested, covered by the hero, offscreen or in a hidden tab. Reduced motion and no JavaScript display a static quilt. There is no new animation loop or library.

Patches scale from 48–88px on desktop and use 44px squares below 760px. The existing stronger mobile reading veil preserves legibility. All illustrations remain decorative and pointer-transparent. The original reference photographs are not published.
